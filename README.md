# 汽水音乐自动看广告脚本（优化版 · 无线调试配对）

本项目基于开源项目 [cvabm/qishui](https://github.com/cvabm/qishui) 进行二次开发与逻辑优化。

### 相比原版的改进：
1. **秒退直播间**：识别到屏幕顶部出现「关注」或「更多直播」等特征时，立即触发手机返回键，不用傻等。
2. **精准过滤标题**：修复原版把「再看XX秒继续解锁」倒计时误当成按钮点击导致的无限死循环问题。
3. **防卡死兜底**：当连续多次未能识别到广告目标时，自动执行返回操作，防止停留在未知页面。
4. **免数据线**：ADB 连接改为 Android 无线调试（`adb pair` + `adb connect`），主推**电脑生成二维码、手机扫码配对**，另备配对码配对与直连。
5. **扫码即配对**：电脑自动生成随机服务名与 6 位配对码并显示二维码，轮询 mDNS 发现手机配对服务后自动完成配对与连接，超时可重试不卡死。
6. **掉线自动重连**：连续截图失败 3 次时自动尝试重连设备，并透传真实 adb 报错，不再无声空转。

## 电脑小白手把手使用教程

### 第一步：手机设置（只需设置一次）
1. 打开手机的 **「设置」** -> **「关于手机」**。
2. 连续快速点击 **「版本号」** 7次以上，直到屏幕提示已开启开发者模式。
3. 返回设置页面，找到 **「开发者选项」**。
4. 开启以下开关：
   - **无线调试**（必须开启，本项目走无线连接，不需要数据线）
   - **USB 调试（安全设置）** 或 **允许模拟点击**（小米/vivo等机型必开，否则脚本只能看不能点）。
5. 手机与电脑连接**同一个 Wi-Fi**（同一路由器；不要一个连 Wi-Fi、一个连手机热点）。

---

### 第二步：安装运行环境
1. 确保电脑已安装 Python 3。
2. 确保电脑上有 adb（Android SDK Platform-Tools）。脚本会自动按以下顺序查找：
   - `--adb` 参数指定的路径 → 环境变量 `ADB_PATH` → 系统 `PATH` → 常见安装目录（如 `C:\platform-tools\adb.exe`、`%LOCALAPPDATA%\Android\Sdk\platform-tools\adb.exe`）。
   - 都找不到时用 `--adb "D:\platform-tools\adb.exe"` 指定即可。
3. 在本项目文件夹上方的地址栏输入 `cmd` 并按回车打开命令行。
4. 输入以下命令安装依赖库并按回车：
   ```bash
   pip install -r requirements.txt
   ```
   > 依赖包含 `opencv-python`、`numpy`、`rapidocr-onnxruntime`，以及扫码配对所需的 `qrcode[pil]` 与 `pillow`（生成二维码图片）。

---

### 第三步：连接手机（无线调试配对）
双击 **`启动.bat`**，或命令行运行 `python qishui_auto.py`。脚本会先检查有没有可用的无线设备：
- **已有设备**：直接进入自动看广告主循环；
- **没有设备**：进入配对菜单，按提示选 `1`/`2`/`3`/`4`/`5`。

> 菜单顺序：`1` 扫码配对（推荐）→ `2` 配对码配对 → `3` 粘贴二维码文本 → `4` 二维码图片解码 → `5` 直连。

#### 方式一：扫码配对（推荐 · 电脑生成二维码，手机扫码）

不用在手机上找配对码，也不用抄 IP 端口，手机扫一下屏幕就行。

1. 双击 **`启动.bat`**，菜单选 **`1` 扫码配对启动**（命令行等价：`python qishui_auto.py --qr-make`）。
2. 电脑自动做三件事：生成随机服务名与 6 位配对码 → 渲染二维码图片 `pair_qr.png`（项目目录）→ 用系统默认看图器把图片弹出来。
3. 手机：设置 → 开发者选项 → **无线调试** → 点 **「使用二维码配对设备」** → 摄像头对准电脑屏幕上的二维码扫描。
4. 手机上点「配对」后，电脑开始轮询 `adb mdns services` 等待手机的配对服务广播；发现后自动执行 `adb pair <IP:端口> <配对码>`，成功再自动 `adb connect`，随后进入看广告主循环。

```bash
python qishui_auto.py --qr-make                 # 扫码配对（推荐）
python qishui_auto.py --qr-make --pair-wait 300 # 手机对焦慢时，把等待时间从 180s 放宽
python qishui_auto.py --qr-make --no-open       # 不自动弹看图器，自己打开图片扫码
```

说明：
- 二维码内容为 `WIFI:T:ADB;S:<随机服务名>;P:<6位配对码>;;`，服务名与配对码**每次运行随机生成**，过期即失效，无需手工输入。
- 默认最多等待 **180 秒**；超时**不会死循环**，会让你选择「继续等待 / 重新生成二维码 / 放弃扫码配对」。
- 扫不动时：调高屏幕亮度、把二维码窗口放大后再扫；仍然不行就用下面的配对码方式。

#### 方式二：配对码配对（手机显示 6 位码）
1. 手机：设置 → 开发者选项 → **无线调试** → 打开 → 点 **「使用配对码配对设备」**。
2. 手机弹窗显示 **6 位配对码** 和 **IP 地址和端口**（例如 `192.168.1.5:37000`）。
3. 电脑菜单选 `2`：
   - 配对地址选 `1` 自动发现（脚本自动扫描 `_adb-tls-pairing._tcp`）；
   - 若没扫到，选 `2` 并手动输入手机页面上的 `IP:端口`；
   - 再输入 6 位配对码。
4. 配对成功后脚本自动 `adb connect` 连接端口，并等待设备进入 `device` 状态。

> 地址必须是完整 `IP:端口`。只填端口（如 `41197`）时脚本会尝试用 mDNS 里的手机 IP 补全，补不全就会明确拒绝并提示重填，**不会**再发出 `adb pair 41197` 这种缺 IP 的错误命令（旧版的 `protocol fault` 就是它导致的）。

命令行等价写法：
```bash
python qishui_auto.py --pair-code 123456
python qishui_auto.py --pair-code 123456 --pair-addr 192.168.1.5:37000
```

#### 方式三：二维码配对（粘贴文本 / 图片解码）

Android 11+ 的「使用二维码配对设备」会生成二维码，内容形如：
```text
WIFI:T:ADB;S:adb-XXXXXX-YYYYYY;P:123456;;
```
脚本支持两种输入方式：

- **粘贴二维码文本**：菜单选 `3`，或
  ```bash
  python qishui_auto.py --qr-text "WIFI:T:ADB;S:adb-XXXXXX-YYYYYY;P:123456;;"
  ```
- **二维码图片**（把截图/照片存到电脑）：菜单选 `4` 后把图片拖进窗口，或
  ```bash
  python qishui_auto.py --qr-image "D:\图片\adb_qr.png"
  ```
  图片由 OpenCV 解码，分辨率过低或缺少白边时会自动放大、补白边重试。

> 二维码里只有「配对服务名 + 配对码」，不含连接地址。脚本会用服务名到 mDNS 里找对应的连接端口，找不到时再请你手动输入连接端口。

#### 方式四：直连已开启无线调试的设备
之前配对过、只是端口变化时（菜单选 `5`）：
```bash
python qishui_auto.py --connect-addr 192.168.1.5:37123
```
已连接设备无需再次配对时，用 `--skip-pair`；需要强制重新配对时用 `--repair`。

1. 手机打开 **汽水音乐**，进入看广告领时长页面。
2. 保持手机屏幕常亮，不要锁屏。
3. 连接成功、控制台显示 `✅ OCR 就绪` 后，脚本开始全自动运行。

## 常用参数速查

| 参数 | 说明 |
| --- | --- |
| `--adb <路径>` | 指定 adb.exe 路径（也可用环境变量 `ADB_PATH`） |
| `--qr-make` | **扫码配对（推荐）**：电脑生成二维码并自动打开，手机扫码 |
| `--pair-wait <秒>` | 扫码后等待手机配对服务广播的最长秒数（默认 180） |
| `--no-open` | 生成二维码后不自动打开看图器 |
| `--pair-code <6位>` | 配对码配对，自动发现配对端口 |
| `--pair-addr <IP:端口>` | 手动指定配对地址（配合 `--pair-code`，必须含 IP 与端口） |
| `--qr-text <文本>` | 备选：粘贴二维码文本后配对 |
| `--qr-image <图片路径>` | 备选：从二维码图片解码后配对 |
| `--connect-addr <IP:端口>` | 直连已开启无线调试的设备 |
| `--skip-pair` | 跳过配对，直接使用已连接设备 |
| `--repair` | 忽略已连接设备，强制重新配对 |
| `--diag` | 只打印连接诊断（adb 路径 / 设备列表 / mDNS 服务），不进入主循环 |

## 常见问题

- **二维码没有自动弹出**：部分系统没绑定图片查看器。手动双击项目目录下的 `pair_qr.png` 打开即可；或先加 `--no-open` 自行打开。
- **扫码后电脑一直等**：① 手机上是否点了「配对」；② 手机与电脑是否同一 Wi-Fi（关掉手机热点、路由器关 AP 隔离）；③ 防火墙是否拦截 mDNS（UDP 5353）与 adb；④ 另开一个窗口执行 `adb mdns services` 看有没有 `_adb-tls-pairing._tcp`。超时后按提示选「重新生成二维码」重试。
- **提示缺少 qrcode 库**：执行 `pip install "qrcode[pil]" pillow` 后重跑。
- **`配对失败 error: protocol fault`**：多半是配对码过期或配对地址不完整。手机上重新点「使用配对码配对设备」/ 重新扫码后再试；手工填地址时务必是完整 `IP:端口`。
- **`cannot connect ... 拒绝连接`**：无线调试被关闭或端口已变。重新打开无线调试，用 `--diag` 查看 mDNS 最新端口，或重新配对。
- **mDNS 扫不到设备**：确认手机与电脑同一 Wi-Fi、路由器未开 AP 隔离；也可手动输入手机页面上的 `IP:端口`。
- **能看不能点**：回到开发者选项打开「USB 调试（安全设置）」/「允许模拟点击」。
- **一直截图失败**：脚本会打印真实 adb 报错，并在连续 3 次失败后自动尝试重连；仍失败请按报错提示检查连接。

> 首次连接较慢是因为 mDNS 需要几秒广播时间，之后再次运行会直接复用已连接设备。
